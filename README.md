# 📝 MyNotes - 스마트 노트 앱

완전한 기능을 갖춘 웹 기반 노트 작성 애플리케이션입니다. 순수 HTML, CSS, JavaScript로 제작되었으며, 로컬 스토리지를 사용하여 모든 데이터를 안전하게 저장합니다.

## ✨ 주요 기능

### 📋 노트 관리
- ✏️ **노트 작성/편집/삭제** - 직관적인 인터페이스로 쉽게 노트 관리
- 📁 **폴더 시스템** - 계층적 폴더 구조로 노트 정리
- ⭐ **즐겨찾기** - 중요한 노트를 즐겨찾기에 추가
- 🔒 **노트 잠금** - 비밀번호로 민감한 노트 보호
- 🏷️ **태그 시스템** - 다중 태그로 노트 분류

### 🎨 리치 텍스트 에디터
- **서식 지원**: 굵게, 기울임, 밑줄, 취소선
- **제목**: H1, H2, H3 제목 스타일
- **목록**: 번호 매기기, 글머리 기호
- ☑️ **체크리스트** - 할 일 관리
- 🎨 **색상**: 글자 색상 및 배경 색상 변경
- ✏️ **그리기 레이어** - 노트 위에 그림/주석 추가
  - 펜, 지우개, 형광펜 도구
  - 색상 및 굵기 조절
  - 모바일 터치 지원

### 🔍 검색 및 필터
- **전체 텍스트 검색** - 노트 제목, 내용, 태그 검색
- **정렬 옵션**:
  - 최근 수정순
  - 생성일순
  - 제목순

### 💾 데이터 관리
- **로컬 스토리지** - 모든 데이터를 브라우저에 안전하게 저장
- **자동 저장** - 3초마다 자동으로 저장
- **내보내기**:
  - JSON (전체 백업)
  - TXT (현재 노트)
  - HTML (현재 노트)
- **가져오기** - JSON 백업 파일에서 데이터 복원

### 🎨 UI/UX
- 🌙 **다크 모드** - 라이트/다크 모드 전환
- 📱 **반응형 디자인** - 모바일, 태블릿, 데스크톱 지원
- ⌨️ **키보드 단축키**:
  - `Ctrl+B` - 굵게
  - `Ctrl+I` - 기울임
  - `Ctrl+U` - 밑줄
  - `Ctrl+S` - 저장
- 🎯 **직관적인 인터페이스** - 최소한의 학습으로 바로 사용 가능

## 🚀 시작하기

### 설치 방법

1. 저장소 클론:
```bash
git clone <repository-url>
cd notion
```

2. 웹 브라우저에서 `index.html` 파일 열기

그게 전부입니다! 별도의 설치나 서버가 필요하지 않습니다.

### 사용 방법

1. **새 노트 만들기**
   - 사이드바의 "✏️ 새 노트" 버튼 클릭
   - 또는 환영 화면에서 "첫 노트 만들기" 클릭

2. **노트 편집**
   - 제목과 내용 입력
   - 툴바에서 서식 도구 사용
   - 태그 추가 (# 입력 후 엔터)

3. **그림 그리기**
   - "✏️ 그리기" 버튼 클릭
   - 펜, 지우개, 형광펜 중 선택
   - 색상과 굵기 조절
   - "✅ 완료" 버튼으로 저장

4. **노트 잠금**
   - 노트 열기
   - 상단의 잠금 버튼 (🔓) 클릭
   - 비밀번호 설정

5. **데이터 백업**
   - 하단의 💾 아이콘 클릭
   - "📋 JSON (전체 백업)" 선택
   - 파일 다운로드

```
notion/
├── index.html      # 메인 HTML 파일
├── styles.css      # 스타일시트 (다크 모드 포함)
├── app.js          # 애플리케이션 로직
└── README.md       # 프로젝트 문서
```

## 🛠️ 기술 스택

- **HTML5** - 시맨틱 마크업
- **CSS3** - CSS 변수, Flexbox, Grid, 애니메이션
- **JavaScript (ES6+)** - 클래스, 화살표 함수, 모듈화
- **Canvas API** - 그리기 레이어
- **LocalStorage API** - 데이터 저장
- **Web Share API** - 노트 공유 (지원 브라우저)

## 🔒 보안 및 개인정보

- 모든 데이터는 **로컬 브라우저에만 저장**됩니다
- 서버로 전송되는 데이터가 없습니다
- 노트 잠금 기능으로 민감한 정보 보호
- 비밀번호는 해시되어 저장됩니다 (단순 해시 - 프로덕션에서는 더 강력한 암호화 권장)
